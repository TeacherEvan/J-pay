1. Executive Triage Summary

J-pay is a geofenced employee time-tracking, shift-derivation, and multi-jurisdiction payroll PWA that suffers from severe Dual-Backend Split-Brain and Iterative Vibe-Debt. The repository simultaneously maintains a complete 24-module Convex backend (convex/*) alongside a parallel Supabase PostgreSQL stack (supabase/migrations/0001_init.sql, src/lib/supabase/*), bridged by a custom RPC proxy (src/app/api/backend/call/route.ts) and custom React deduplication hooks (src/lib/backend/react.ts). Four consecutive failed or stalled agent refactoring attempts on src/app/check-in-card.tsx (plans/2026-09-04 through 2026-09-09) and committed runtime crash dumps (docs/UserReview/Error Type Runtime ConvexError.md) confirm brittle state boundaries, unresolved authentication desyncs, and monolithic UI components.

        export function flushOutboxSerialized(sendFn: (item: OutboxEntry) => Promise<void>): Promise<FlushResult> {
          if (activeFlushPromise) return activeFlushPromise;
          activeFlushPromise = (async () => {
            try {
              const items = loadOutboxEntriesSortedByTimestamp();
              for (const item of items) {
                await sendFn({ ...item, idempotencyKey: item.id }); // Server deduplicates by idempotencyKey
